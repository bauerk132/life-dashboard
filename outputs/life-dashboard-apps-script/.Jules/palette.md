## 2024-10-19 - Improved form accessibility with aria-invalid and aria-hidden
**Learning:** For required UI form inputs, improve accessibility by adding a visual asterisk wrapped in `<span aria-hidden="true">*</span>` within the label alongside the native `required` attribute. This prevents screen readers from redundantly announcing the asterisk. Linking inputs to error messages via `aria-describedby` and dynamically toggling `aria-invalid='true'` ensures errors are contextually announced.
**Action:** Always pair visual indicators (like asterisks) with `aria-hidden="true"` when native attributes (like `required`) are already doing the semantic work. Ensure error messages are explicitly linked with `aria-describedby` and `aria-invalid` is properly toggled on input validation failure.
